## 💻 Proyecto destacado: **Prueba – Panadería Web**

<p align="center">
  <img src="https://via.placeholder.com/800x400.png?text=Dashboard+Panader%C3%ADa" alt="Proyecto Panadería" width="700"/>
</p>

**Descripción:**  
Aplicación web para la gestión interna de una panadería. Permite controlar **productos, usuarios, ventas y estadísticas**, con interfaz moderna y lógica en Java.

**Tecnologías usadas:** Java, Maven, CSS, Azure Data Studio, Linux  

**Funcionalidades principales:**  
- 👤 Gestión de usuarios: registro, edición, eliminación  
- 🛍 Administración de productos  
- 💰 Control de ventas y stock  
- 📊 Panel de control con estadísticas  

**Cómo ejecutar:**  
```bash
git clone https://github.com/Eduarcito/prueba.git
cd prueba
mvn clean install
mvn tomcat7:run   # si usas Tomcat
