Este proyecto es una **aplicación web para la gestión interna de una panadería**, desarrollada con Java y Maven, con interfaz en CSS y base de datos en Azure Data Studio.
</p>

---

## 🛠 Tecnologías utilizadas  
- ☕ **Java 17**  
- 📦 **Maven**  
- 🎨 **CSS**  
- 🖥 **Azure Data Studio** (base de datos SQL)  
- 🐧 **Linux**  
- 💻 **Visual Studio Code**
