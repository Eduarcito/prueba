## ✨ Sobre el proyecto

**Prueba – Panadería Web** es una **aplicación web** diseñada para facilitar la **gestión interna de una panadería**.  
Permite manejar **productos, usuarios, ventas y estadísticas**, todo desde un panel de control intuitivo y moderno.  

💡 **Propósito:**  
Hacer que la administración de una panadería sea más rápida, ordenada y eficiente, combinando **funcionalidad y diseño**.
